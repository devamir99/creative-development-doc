## Brief

Each case study shares a visual language (motif + motion verb) but still breathes with pacing and clean cuts.

## Technique stack

| Need | Technique |
| --- | --- |
| Recognition | Shared wipe / accent |
| Case open | Stagger + anticipation |
| Between cases | Hard cut or short wipe |
