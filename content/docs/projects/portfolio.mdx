# Immersive Portfolio

## Brief

A portfolio where each case study shares a visual language (motif + motion verb) but still breathes with pacing and clean cuts.

## Technique stack

| Need | Technique |
| --- | --- |
| Recognition | Shared motif / accent / wipe |
| Case open | Anticipation + stagger of media |
| Between cases | Hard cut or short wipe — not every dissolve |
| Depth | Mild parallax on case heroes |

## Implementation notes

- Prefetch next case media on near-viewport.
- Keep typography LTR for code blocks even in localized chrome.
- Critique each case with the [Critique Loop](/docs/direction/critique).
