# صفحه فرود سینمایی

## اول ببین

چهار فصل با برش‌های سخت. سکانس را پخش کن — به یک اکسنت و انرژی مکثِ در حال تغییر توجه کن. این همان الگو در ابعاد کوچک است.

<CinematicLandingPlayground />

## بریف

یک صفحه فرود منتشر کن که کارگردانی‌شده حس شود: یک بیانیه هیرو، فصل‌های اسکرولی با برش‌های عمدی و حرکتی که به reduced-motion احترام می‌گذارد.

## پشته تکنیک

| ضرب | تکنیک |
| --- | --- |
| هیرو | نقطه کانونی واضح + یک CTA |
| اتصال فصل‌ها | برش سخت به‌صورت پیش‌فرض |
| اسکرول | پیشرفت ScrollTrigger (وب خلاقانه را ببین) |
| CTA | اکسنت مشترک + پیش‌آمادگی |
