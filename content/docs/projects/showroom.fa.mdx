# نمایشگاه دیجیتال تعاملی

## اول ببین

<ProductHotspotPlayground />

نمایشگاه یک صحنه محصول با ناوبری فضایی است: وارد شو، جهت‌یابی کن، کاوش کن، بازرسی کن، مقایسه کن و تماس بگیر/بخر.

## بریف پروژه

یک نمایشگاه دیجیتال برای یک خانواده محصول بساز. کاربران می‌توانند یک تور هدایت‌شده را دنبال کنند یا آزادانه کاوش کنند. هر ایستگاه یک هیروی بصری، جزئیات هات‌اسپات، حال‌وهوای نورپردازی و یک اقدام بعدی واضح دارد.

## ساختار تجربه

```text
Arrival → orientation → guided path → free exploration → deep inspection → shortlist/compare → CTA
```

## پشته تکنیک

| نیاز | تکنیک آزمایشگاه |
|---|---|
| جهت‌یابی فضایی | دوربین واید/استبلشینگ |
| سفر هدایت‌شده | دوربین اسکرولی یا مسیر دوربین |
| بازرسی | چرخش مداری + نمای نزدیک + عمق میدان |
| کشف جزئیات | هات‌اسپات‌های ری‌کست |
| حال‌وهوا | نورپردازی سه‌نقطه‌ای + مهار مه و بلوم |
| سکانس | برش‌ها، ریتم روایت، گذارهای موتیف |
| کارایی | بارگذاری تنبل صحنه‌ها، سقف DPR، رندر درخواستی |

## معماری اطلاعات

1. **ورود:** وعده برند و نمای کل اتاق.
2. **ایستگاه‌ها:** یک محصول/مسئله در هر ناحیه.
3. **بازرسی:** چرخش مداری، متریال‌ها، ابعاد، هات‌اسپات‌ها.
4. **مقایسه:** دوربین و نورپردازی سازگار در میان محصول‌ها.
5. **فهرست کوتاه:** آیتم‌های ذخیره‌شده و خلاصه.
6. **CTA:** تماس، پیکربندی، خرید یا رزرو.

## برنامه پیاده‌سازی

1. اول صفحه‌های محصول معنایی و ایستا بساز.
2. یک ایستگاه سه‌بعدی اضافه کن و کارایی را اعتبارسنجی کن.
3. هات‌اسپات‌هایی با معادل فهرستیِ قابل‌دسترسی با صفحه‌کلید اضافه کن.
4. مسیر دوربین هدایت‌شده با امکان ردکردن/خروج اضافه کن.
5. حالت مقایسه با دوربین/نور قفل‌شده اضافه کن.
6. GPU موبایل و بارگذاری را پروفایل کن.

## الزامات دسترس‌پذیری

- هر هات‌اسپات سه‌بعدی یک معادل دکمه/فهرست متنی دارد.
- تورهای هدایت‌شده می‌توانند متوقف، رد و خارج شوند.
- حالت reduced-motion به یک فهرست فصل تبدیل می‌شود.
- مشخصات محصول محتوای واقعی DOM است، نه فقط برچسب‌های کانوس.

## الزامات کارایی

- دارایی‌های اتاق را بر اساس ایستگاه تنبل‌بار کن.
- هندسه/متریال‌ها را دوباره استفاده کن.
- برای DPR و اندازه نقشه‌های سایه سقف بگذار.
- مدل‌ها/بافت‌ها را فشرده کن؛ پیشرفت بارگذاری را نشان بده.
- کانوس‌های خارج از صفحه را متوقف کن.

## خطاهای رایج

- اتاقی زیبا که کاربران در آن نمی‌توانند محصول‌ها را پیدا کنند
- دوربین آزاد بدون جهت‌یابی یا ریست
- هات‌اسپات‌هایی که فقط با هاور تصادفی کشف می‌شوند
- نورپردازی متفاوت که رنگ محصول‌ها را غیرقابل‌مقایسه می‌کند
