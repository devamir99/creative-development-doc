# پورتفولیوی غوطه‌ور

## اول ببین

میان موردها جابه‌جا شو — همان وایپ زرد هر بار بازمی‌گردد. شناخت، بدون اینکه کل چیدمان کلون شود.

<PortfolioMotifPlayground />

## بریف

هر مطالعه موردی یک زبان بصری مشترک دارد (موتیف + فعل حرکت) اما همچنان با ریتم روایت و برش‌های تمیز نفس می‌کشد.

## پشته تکنیک

| نیاز | تکنیک |
| --- | --- |
| شناخت | وایپ / اکسنت مشترک |
| بازشدن مورد | پلکانی + پیش‌آمادگی |
| میان موردها | برش سخت یا وایپ کوتاه |
