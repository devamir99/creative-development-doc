# برش J و برش L

## مقدمه

در **برش مستقیم (straight cut)** تصویر و صدا با هم عوض می‌شوند. **برش J (J-Cut)** اجازه می‌دهد صدای *ورودی* قبل از تصویر برسد. **برش L (L-Cut)** اجازه می‌دهد صدای *خروجی* زیر تصویر تازه بماند. نام‌ها از شکلی می‌آید که این جداسازی‌ها روی تایم‌لاین می‌سازند.

## چرا مهم است

- دیالوگ و امبیانس می‌توانند توجه را قبل از رسیدن چشم بکشند.
- تعویض صحنه را بدون دی‌زالو نرم می‌کند.
- در وب: پیش‌بارگذاری صدا / روایت قبل از فصل بصری، یا نگه‌داشتن bed زیر تعویض UI.

## توضیح بصری

```text
J-cut:   picture  AAAAAAAAAAAAA|BBBBBBB
         sound    AAAAA|BBBBBBBBBBBBBBB

L-cut:   picture  AAAAAAAAAAAAA|BBBBBBB
         sound    AAAAAAAAAAAAAAAA|BBBB
```

نشانگر سفید = برش تصویر؛ زرد = برش صدا در زمین بازی.

## پارامترها

| کنترل | نقش |
| --- | --- |
| Mode | J / L / straight |
| Audio offset | صدا چقدر جلو یا عقب برش تصویر می‌افتد |

## مثال‌های عملی

۱. **VO فصل** — برش J: خط بعدی راوی را قبل از تعویض هیرو بشنو.
۲. **گالری** — برش L: bed امبیانس را زیر تعویض سخت تصویر نگه دار.
۳. **کات‌سین بازی** — با SFX ضربه جلو برو قبل از عوض شدن زاویه دوربین.

## پیاده‌سازی

دو زمان برش را ردیابی کن:

```js
const pictureCut = 0.5;
const soundCut = pictureCut - offset; // J
// const soundCut = pictureCut + offset; // L
```

نمایانی تصویر را از `pictureCut` و منبع صدا را از `soundCut` بران.

## نکات کارایی

- اگر برش J باید روی اولین ژست شلیک شود، صدا را زود decode / unlock کن.
- gain و تصویر را بدون تایم‌لاین مشترک روی ساعت‌های متضاد متحرک نکن.

## خطاهای رایج

- آفست‌های خیلی بزرگ که اشتباه حس می‌شوند، نه lead-in
- برش J به سکوت (صدای «B» برای پیش‌بردن نیست)
- فراموش کردن کپشن وقتی صدا جلوتر از تصویر است

## کی استفاده کنی / نکنی

**استفاده کن** برای چسباندن احساسی صحنه‌ها یا پیش‌نمایی.

**پرهیز کن** وقتی تصویر تازه باید با ضربه هم‌زمان فرود بیاید (sting لوگو، تأیید UI).

## نکات کلیدی

- تصویر و صدا محورهای تدوین مستقل‌اند.
- J با صدای B جلو می‌رود؛ L صدای A را دنبال می‌کند.
- آفست‌های کوچک اغلب گران‌تر از بزرگ‌ها حس می‌شوند.
