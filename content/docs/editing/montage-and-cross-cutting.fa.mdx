# مونتاژ، برش موازی و تدوین ریتمیک

## اول ببین

<CutTimelinePlayground />

از تایم‌لاین برای حس موقعیت برش استفاده کن. بعد چند نما پشت‌سرهم را تصور کن: معنا داخل یک نما به‌تنهایی نیست — از ترتیب و ریتم بیرون می‌آید.

## مقدمه

**مونتاژ (Montage)** با کنارهم‌گذاشتن نماها معنا می‌سازد. **برش موازی (Cross-Cutting)** بین کنش‌های موازی جابه‌جا می‌شود. **تدوین ریتمیک** طول نما را عوض می‌کند تا تمپو، فشار یا آرامش بسازد.

## الگوهای اصلی

| الگو | ساختار | اثر |
|---|---|---|
| Metric montage | نماها با طول اندازه‌گیری‌شده | نبض، شتاب |
| Rhythmic montage | طول از حرکت/کنش پیروی می‌کند | تمپوی بدنی |
| Tonal montage | نماها با حال/نور/رنگ پیوند می‌خورند | تداعی احساسی |
| Intellectual montage | مفاهیم متضاد برخورد می‌کنند | ایده یا استدلال |
| Cross-cutting | صحنه‌های موازی A/B/A/B | تعلیق، مقایسه، همگرایی |
| Montage sequence | تکه‌های فشرده | گذر زمان، تمرین، ساختن |

## چرا مهم است

تجربه‌های وب توالی‌اند: هیرو، اثبات، محصول، داستان، CTA. ترتیب علیت را آموزش می‌دهد. برش موازی می‌تواند قبل/بعد یا مسئله/راه‌حل را مقایسه کند. ریتم می‌تواند صفحه را آرام، فوری یا پریمیوم حس کند.

## توضیح بصری

دو نمای بی‌ضرر کنار هم می‌توانند معنای سومی بسازند. چهره‌ای که بعدش غذا می‌آید با همان چهره که بعدش خطر می‌آید فرق می‌کند. توالی یعنی تألیف.

## پارامترها

| پارامتر | اثر |
|---|---|
| Shot duration | تمپو و تأکید |
| Order | علیت و تفسیر |
| Repetition | موتیف، آیین، کمدی، وحشت |
| Acceleration | کوتاه‌کردن نماها فشار را زیاد می‌کند |
| Parallel contrast | صحنه‌های برش‌موازی روی هم نظر می‌دهند |

## کاربردهای عملی

۱. **فیلم لانچ محصول:** تکه‌های متریال، کرافت، استفاده، نتیجه.
۲. **کیس‌استادی:** مسئله / فرآیند / نتیجه با برش موازی.
۳. **آنبوردینگ:** مونتاژ پیشرفت راه‌اندازی را فشرده می‌کند.
۴. **لوپ سوشال/هیرو:** برش‌های ریتمیک هم‌زمان با تایپ یا موسیقی.

## پیاده‌سازی

در حرکت وب، صحنه‌ها را برچسب تایم‌لاین بگیر و مدت‌ها را صریح تعریف کن.

```ts
tl.to(".scene-a", { autoAlpha: 1, duration: .4 })
  .to(".scene-b", { autoAlpha: 1, duration: .25 }, "+=0.1")
  .to(".scene-c", { autoAlpha: 1, duration: .15 });
```

کوتاه‌کردن مدت‌ها شتاب می‌سازد؛ فقط به حرکت سریع‌تر داخل نماها تکیه نکن.

## خطاهای رایج

- برش‌های سریع تصادفی با نام «انرژی»
- برش موازی صحنه‌هایی که هرگز همگرا نمی‌شوند یا نظر نمی‌دهند
- مونتاژ بدون موتیف یا پیشرفت
- ریتم تدوینی که با زمان خواندن متن می‌جنگد

## دسترس‌پذیری

برش و فلش سریع می‌تواند آسیب‌زا باشد. از فلش با فرکانس بالا پرهیز کن، حرکت کاهش‌یافته را احترام بگذار و خلاصه ایستا بده.

## کی استفاده کنی / نکنی

برای فشردن زمان و ساختن تداعی از مونتاژ استفاده کن. در سکانس‌های آموزشی که تداوم و جغرافیا باید کاملاً روشن بمانند، پرهیز کن.

## نکات کلیدی

- توالی معنا می‌سازد.
- ریتم با الگوهای مدت کنترل می‌شود.
- صحنه‌های موازی وقتی قدرت می‌گیرند که همگرا شوند.
