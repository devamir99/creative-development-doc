# برش و تداوم

## مقدمه

**برش (Cut)** اتصال آنی بین دو نماست. تدوین تداوم تلاش می‌کند فضا، زمان و کنش را در این اتصالات خوانا نگه دارد. تدوین‌های سبکی (جامپ‌کات، مچ‌کات) تداوم را عمداً می‌شکنند یا خم می‌کنند.

## چرا مهم است

- ریتم یک تجربه اغلب در تدوین تصمیم گرفته می‌شود، نه در نما.
- در وب، «برش» به‌صورت تغییر مسیر، تعویض صحنه اسکرولی و seek تایم‌لاین ظاهر می‌شود.
- تداوم بد تصادفی حس می‌شود؛ ناپیوستگی خوب مؤلفانه حس می‌شود.

## توضیح بصری

| برش | نیت |
| --- | --- |
| Hard cut | تعویض تمیز — اطلاعات تازه همین حالا |
| Dissolve | نرم‌کردن زمان / حافظه / حال‌وهوا |
| Jump cut | فشردن زمان داخل یک زبان قاب‌بندی |
| Match cut | پل از طریق شکل، حرکت یا ایده مشترک |

## مثال‌های عملی

۱. **فصل‌های اسکرول لندینگ** — برش سخت بین بخش‌ها؛ دی‌زالو فقط برای ضرب‌های «حافظه».
۲. **داستان محصول** — مچ‌کات از علامت لوگو → سیلوئت محصول.
۳. **آموزش UI** — جامپ‌کات داخل یک ضبط صفحه برای رد کردن زمان بیکار.

## پیاده‌سازی

ایده‌های تدوین به کد حرکت نگاشت می‌شوند، نه به یک NLE فیلم:

```js
// برش سخت ≈ تعویض visibility / مسیر در t
// دی‌زالو ≈ کراس‌فید opacity
// جامپ ≈ همان زبان دوربین، زمان ناپیوسته
// مچ ≈ موتیف transform مشترک بین A و B
```

## نکات کارایی

- برای گذارها opacity / transform / clip-path را به filter blur ترجیح بده.
- یک تایم‌لاین در حال پخش در هر لحظه؛ روی unmount بکش.

## خطاهای رایج

- جامپ‌کات بدون دلیل روشن فشردن زمان
- مچ‌کات‌هایی که فقط رنگ مشترک دارند، نه ساختار
- دی‌زالو روی هر تعویض صحنه (ریتم گل‌آلود)

## کی استفاده کنی / نکنی

**استفاده کن** از برش سخت برای وضوح؛ دی‌زالو برای زمان نرم؛ مچ برای قافیه مفهومی.

**پرهیز کن** از انباشتن سه سبک گذار در یک سکانس کوتاه مگر اینکه پارودی هدف باشد.

## نکات کلیدی

- تداوم قراردادی با حس فضایی بیننده است.
- برش‌های سبکی وقتی کار می‌کنند که شکست عمدی و خوانا باشد.
- تدوین وب همان دستور زبان را با ابزارهای متفاوت به ارث می‌برد.
