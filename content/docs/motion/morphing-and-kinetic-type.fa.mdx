# مورفینگ و تایپوگرافی جنبشی

## اول ببین

<MorphPlayground />

بعد از کاوش مورف، در همان خانواده playground به **تایپوگرافی جنبشی (Kinetic Typography)** برو: حروف می‌توانند وارد شوند، کش بیایند، جمع شوند و خود پیام شوند.

<KineticTypePlayground />

## مقدمه

**مورفینگ** یک شکل/حالت را به دیگری تبدیل می‌کند در حالی که حس هویت حفظ شود. **تایپوگرافی جنبشی** تایپوگرافی در حرکت است: حروف و واژه‌ها مطابق ریتم، صدا و معنا حرکت می‌کنند.

## انواع مورف

| مورف | نشانه تداوم |
|---|---|
| Border-radius | مربع به ارگانیک/دایره نرم می‌شود |
| Path morph | خط بیرونی SVG به خط دیگری بدل می‌شود |
| ترکیب scale/rotation | جسم از طریق حرکت دگرگون می‌شود |
| Layout/FLIP | عنصر موقعیت/اندازه عوض می‌کند ولی هویت می‌ماند |
| Mask reveal | شکل جدید از میان شکل قدیم ظاهر می‌شود |

## اصول تایپ جنبشی

- حرکت باید لحن را بیان کند: فریاد، نجوا، لغزش، جشن.
- ترتیب خواندن باید از انیمیشن جان سالم به‌در ببرد.
- پلکانی حروف به‌خودی‌خود معنادار نیست.
- تایپ بزرگ می‌تواند صحنه باشد؛ تایپ کوچک باید خوانا بماند.
- برای متن فارسی، واحد حرکت را روی واژه یا گروه معنایی نگه دار — شکستن حروف متصل پارسی خوانایی و شکل کلمه را خراب می‌کند. دموهای لاتین ممکن است حرف‌به‌حرف باشند؛ همان الگو را روی پارسی کپی نکن.

## چرا مهم است

مورف‌ها وقتی هویت ادامه دارد، دگرگونی را بهتر از برش توضیح می‌دهند. تایپ جنبشی می‌تواند زبان را در لانچ، ویژوال موسیقی، آموزش و فیلم برند فیزیکی کند.

## پارامترها

| پارامتر | اثر |
|---|---|
| مدت | خوانایی دگرگونی |
| شکل میانی | مورف مایع، مکانیکی یا جادویی حس شود |
| پلکانی به‌ازای حرف/واژه | ریتم خواندن |
| ردشدن از هدف | بازیگوشی و تأکید |
| نگه‌داشتن حالت پایانی | زمان واقعی خواندن |

## کاربردهای عملی

۱. **دکمه پخش → مکث:** مورف کوچک هویت را حفظ می‌کند.
۲. **ساخت لوگو:** قطعات به علامت جمع می‌شوند.
۳. **تیتر لانچ:** واژه‌ها با گروه‌های معنایی می‌رسند، نه حروف تصادفی.
۴. **تغییر حالت داده:** نوار فقط وقتی به دونات مورف می‌شود که نگاشت هویت روشن باشد.

## پیاده‌سازی

برای مورف مسیر SVG از ساختارهای سازگار یا پلاگین اختصاصی استفاده کن. برای تایپ، اول بر اساس واژه جدا کن؛ حروف را فقط برای متن نمایشی کوتاه لاتین جدا کن و متن دسترس‌پذیر را حفظ کن. روی فارسی از شکستن حرف‌به‌حرف خودداری کن — واژه یا عبارت را واحد نگه دار.

```ts
gsap.from(".word", { y: 40, opacity: 0, stagger: 0.08, ease: "power3.out" });
```

## خطاهای رایج

- مورف اشیای بی‌ربط بدون هندسه مشترک
- انیمیشن حرف‌به‌حرف برای پاراگراف‌های بلند (و به‌ویژه متن پارسی متصل)
- متنی که موقع انتظار خواندن کاربر هنوز حرکت می‌کند
- خواننده‌های صفحه که حروف تکه‌تکه دریافت می‌کنند

## کارایی و دسترس‌پذیری

متن کامل را در DOM/درخت دسترس‌پذیری نگه دار. از شکستن کپی بلند پرهیز کن. حرکت کاهش‌یافته باید متن نهایی را فوری نشان دهد.

## کی استفاده کنی / نکنی

مورف را برای تغییراتی که هویت را حفظ می‌کنند استفاده کن. برای دگرگونی‌های پیچیده داده که برش به‌علاوه برچسب واضح‌تر است پرهیز کن.

## نکات کلیدی

- مورف = تداوم از میان دگرگونی.
- تایپ جنبشی = زبان با طراحی حرکت.
- حالت نهایی خواندن مهم‌تر از ترفندهای ورود است.
