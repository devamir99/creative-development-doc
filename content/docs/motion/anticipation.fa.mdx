# پیش‌آمادگی، دنباله و ردشدن از هدف

## اول ببین

<AnticipationPlayground />

اول جسم کمی به عقب می‌رود. بعد پرتاب می‌شود. بعد رد می‌شود یا می‌نشیند. جمع‌شدن را بردار و عمل کمتر آماده‌به‌نظر می‌رسد.

## مقدمه

انیمیشن کلاسیک یک حرکت را به یک عبارت می‌شکند:

```text
Anticipation → Main action → Follow-through / Overshoot → Settle
```

## تعاریف

| فاز | معنا |
|---|---|
| پیش‌آمادگی (Anticipation) | حرکت آماده‌ساز مخالف |
| عمل اصلی | جابه‌جایی/تغییر اصلی |
| دنباله (Follow-through) | بخش‌های متصل بعد از توقف بدنه ادامه می‌دهند |
| ردشدن از هدف (Overshoot) | جسم اصلی به‌خاطر انرژی از هدف رد می‌شود |
| نشست (Settle) | انرژی در حالت نهایی پخش می‌شود |

## چرا مهم است

مغز آماده‌سازی را به‌عنوان نیت می‌خواند. پرش بدون خم‌شدن بی‌وزن حس می‌شود. پنلی که ناگهان می‌ایستد می‌تواند دیجیتال و شکننده حس شود.

## پارامترها

| پارامتر | اثر |
|---|---|
| فاصله/مدت پیش‌آمادگی | چقدر واضح نیت خوانده می‌شود |
| مدت/ایز عمل اصلی | قدرت عمل |
| مقدار ردشدن | کشسانی/وزن |
| تأخیر دنباله‌رو | شل‌بودن ماده |
| زمان نشست | اطمینان نهایی |

## کاربردهای عملی

۱. **دکمه/CTA:** پیش‌آمادگی فشردن خیلی کوچک، نشست رهاسازی.
۲. **دراور:** مقاومت مخالف خفیف قبل از بازشدن در سیستم‌های بازیگوش.
۳. **پرش شخصیت/جسم:** خم، پرتاب، دنباله مو/پارچه.
۴. **اسنپ محصول:** چند پیکسل/درجه ردشدن، بعد قفل.

## پیاده‌سازی

```ts
gsap.timeline()
  .to(el, { x: -18, duration: .16, ease: "power2.in" })
  .to(el, { x: 240, duration: .5, ease: "power3.out" })
  .to(el, { x: 232, duration: .18, ease: "power1.out" })
  .to(el, { x: 240, duration: .16 });
```

## خطاهای رایج

- پیش‌آمادگی قبل از هر عمل ریز UI
- ردشدن روی خطا، پرداخت، اقدامات مخرب
- دنباله‌ای که قابلیت استفاده را به تأخیر می‌اندازد
- فیزیک کارتونی در زبان بصری جدی

## دسترس‌پذیری

حرکت کاهش‌یافته: بدون جمع‌شدن یا ردشدن؛ حالت نهایی یا محو. هرگز تماشای کامل عبارت را برای تعامل لازم نکن.

## کی استفاده کنی / نکنی

برای اعمال هیرو، محصولات بازیگوش، درگ/اسنپ فیزیکی استفاده کن. برای UI پربازده متراکم و بازخورد فوری پرهیز کن.

## نکات کلیدی

- آماده‌سازی نیت را می‌فروشد.
- دنباله ماده را می‌فروشد.
- نشست اطمینان را می‌فروشد.
