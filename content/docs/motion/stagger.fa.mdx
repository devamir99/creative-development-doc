# پلکانی (Stagger)

## اول ببین

<StaggerPlayground />

یک tween، چند زمان شروع. با پلکانی `0s` گروه مثل یک بلوک حرکت می‌کند؛ با مقادیر بزرگ‌تر موج می‌شود.

## مقدمه

**پلکانی (Stagger)** شروع هر هدف را در یک انیمیشن مشترک به تأخیر می‌اندازد. آبشار، ریتم، ترتیب خواندن و موج‌های مکانیکی یا ارگانیک می‌سازد.

## چرا مهم است

لیست‌ها و گریدها بدون پلکانی می‌توانند مثل یک بلوک سنگین حس شوند. با پلکانی زیاد، کاربر منتظر آخرین آیتم می‌ماند و رابط کند حس می‌شود.

## الگوهای پلکانی

| الگو | ترتیب | حس |
|---|---|---|
| Start | اول → آخر | آبشار خواندن |
| End | آخر → اول | تأکید معکوس |
| Center | وسط به‌سمت بیرون | شکفتن/بازشدن |
| Edges | بیرون به‌سمت داخل | جمع‌شدن |
| Random | بدون ترتیب ثابت | ارگانیک، ذرات — برای ترتیب UI پرریسک |
| Grid | بر اساس ردیف/ستون/قطر | موج فضایی |

## پارامترها

| پارامتر | اثر |
|---|---|
| بازه پلکانی | شکاف بین شروع‌ها |
| مدت هر کدام | طول آیتم فردی |
| مدت کل | آخرین شروع + مدت؛ هزینه ادراکی واقعی |
| ایزینگ | شخصیت هر آیتم |
| مبدأ/ترتیب | منطق خواندن و فضایی |

فرمول زمان کل: `(count - 1) × stagger + duration`.

## کاربردهای عملی

۱. **آیتم‌های ناوبری:** پلکانی 30–60ms.
۲. **کارت‌ها:** 50–90ms، محو/بالاآمدن.
۳. **واژه‌های تیتر:** 60–120ms بر اساس واژه.
۴. **قطعات سه‌بعدی:** با ترتیب ساخت جمع شوند.

## پیاده‌سازی

```ts
gsap.from(".item", {
  y: 28, autoAlpha: 0, duration: .5,
  stagger: { each: .06, from: "start" },
  ease: "power3.out",
});
```

## خطاهای رایج

- پلکانی ده‌ها آیتم تا مدت کل به ثانیه برسد
- ترتیب تصادفی برای محتوایی با سلسله‌مراتب خواندن
- انیمیشن هر لیست در هر تغییر مسیر/فیلتر
- پلکانی آن‌قدر کوچک که فقط لرزش می‌سازد

## کارایی و دسترس‌پذیری

فقط transform/opacity. حرکت کاهش‌یافته باید مجموعه نهایی را نشان دهد. هشدارهای حیاتی را پلکانی نکن.

## کی استفاده کنی / نکنی

برای ورودها و مونتاژها استفاده کن. برای بازخورد فوری و ریزتعامل‌های تکراری پرهیز کن.

## نکات کلیدی

- پلکانی ریتم در یک مجموعه است.
- مدت کل را حساب کن، نه فقط مدت هر کدام.
- ترتیب باید منطق خواندن یا فضایی را آینه کند.
