# حرکت ثانویه و ریتم حرکت

## اول ببین

<SecondaryMotionPlayground />

جسم اصلی پیش می‌رود. دنباله‌رو دیرتر و با انرژی متفاوت می‌رسد. آن تأخیر اتصال و ماده را می‌فروشد.

## مقدمه

**حرکت ثانویه** حرکتی است که از حرکت اولیه ناشی می‌شود: مو بعد از چرخش سر، سایه‌ای که می‌رسد، آیکن‌هایی که پنل را پژواک می‌کنند، شنلی که شخصیت را دنبال می‌کند.

**ریتم حرکت** الگوی ضرب‌ها در یک توالی است — منظم، سنکوپ‌دار، شتاب‌گیر یا آرام.

## چرا مهم است

- حرکت اولیه به‌تنهایی می‌تواند خشک حس شود.
- حرکت ثانویه نرمی، وزن و اتصال را منتقل می‌کند.
- ریتم انیمیشن‌های جدا را به یک زبان بدل می‌کند.

## منابع

| عنصر ثانویه | دنبال می‌کند |
|---|---|
| رد/شبح | جسم هیرو سریع |
| سایه/مقیاس | پرش یا فشردن |
| پارچه/مو | حرکت بدنه |
| عناصر فرزند UI | پنل والد |
| تأخیر دوربین | شخصیت یا اشاره‌گر |

## پارامترها

| پارامتر | اثر |
|---|---|
| تأخیر | چقدر دنباله‌رو عقب است |
| تفاوت مدت | انرژی ثانویه نرم‌تر/کندتر |
| دامنه | پژواک ظریف در برابر رد کارتونی |
| الگوی ریتم | ضرب‌های یکنواخت، گروهی، شتاب‌گیر |
| رابطه پلکانی | پاسخ ثانویه مرتب |

## کاربردهای عملی

۱. **کارت‌ها:** کارت حرکت می‌کند؛ سایه و آیکن بعد می‌نشینند.
۲. **شخصیت/مسکات UI:** گوش، شال یا بج عقب می‌ماند.
۳. **ناوبری:** نشانگر پیش می‌رود، برچسب‌ها ظریف دنبال می‌کنند.
۴. **محصول:** لوازم یا بازتاب‌ها به چرخش واکنش می‌دهند.

## پیاده‌سازی

```ts
tl.to(".hero", { x: 300, duration: .6, ease: "power3.out" })
  .to(".follower", { x: 300, duration: .85, ease: "power2.out" }, "<0.05");
```

دامنه‌های ثانویه را کوچک‌تر نگه دار مگر ماده عمداً شل باشد.

## خطاهای رایج

- هر عنصر با تأخیر تصادفی متفاوت دنبال می‌کند
- حرکت ثانویه چشمگیرتر از عمل اولیه
- ریتمی که به‌قدر کافی تکرار نمی‌شود تا زبان شود
- حرکت بی‌کار دائمی که با خواندن رقابت می‌کند

## کی استفاده کنی / نکنی

برای فروختن ماده و اتصال استفاده کن. در ابزارهای دقیق که پژواک به معنای نادقتی است پرهیز کن.

## نکات کلیدی

- دنباله‌روها باید دیرتر، نرم‌تر و معمولاً کوچک‌تر باشند.
- ریتم تکرار با تنوع است.
- حرکت ثانویه حمایت می‌کند، هرگز وضوح اولیه را جایگزین نمی‌کند.
