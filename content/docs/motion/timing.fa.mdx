# زمان‌بندی

## مقدمه

**زمان‌بندی** یعنی یک حرکت چقدر طول می‌کشد — مدتی که قبل از شکل‌دادن منحنی به یک عمل می‌دهی.

قبل از ایزینگ، پلکانی یا گذارهای فانتزی: تصمیم بگیر چیزی **چقدر** حرکت کند و **چرا**. همان فاصله، مدت‌های متفاوت، حس‌های متفاوت می‌سازد. ایزینگ *چگونگی* توزیع زمان را عوض می‌کند؛ زمان‌بندی تصمیم می‌گیرد *چقدر* زمان وجود دارد.

> یادداشت آموزشی: باندهای حس پایین محدوده‌های شروع عملی‌اند، نه قوانین جهانی. سلیقه، فرهنگ و بافت محصول هنوز مهم‌اند.

## چرا مهم است

مدت عاطفی و کارکردی است.

- خیلی کوتاه → ارزان، ناتمام، یا «شبیه باگ»
- خیلی بلند → کند؛ کاربر منتظر می‌ماند به‌جای خواندن حرکت
- طول درست → مطمئن، عمدی، خوانا

در **سینما**، زمان‌بندی به داستان و دوربین خدمت می‌کند. در **UI**، زمان‌بندی به قابلیت استفاده هم خدمت می‌کند. وب خلاقانه بین هر دو می‌نشیند: شیرجه هیرو می‌تواند حدود 1.8s سینمایی باشد؛ تأیید دکمه معمولاً باید زیر حدود 0.3s بماند.

## توضیح بصری

یک جسم را با **همان فاصله** و **ease none** تماشا کن. فقط مدت را عوض کن.

| مدت | حس معمول |
| --- | --- |
| حدود 0.15–0.2s | تند / مکانیکی / کروم UI |
| حدود 0.4–0.6s | حرکت طبیعی رابط |
| حدود 1–2s | سینمایی / آشکارسازی عمدی |
| 3s+ | حماسی، جوی، آشکارسازی آهسته |

چه در playground ببینی: طول مسیر هرگز عوض نمی‌شود — فقط ساعت. اگر حرکت متفاوت حس شد، آن تفاوت زمان‌بندی است.

از **پخش دوباره** استفاده کن تا همان مدت را دوباره حس کنی. از **بازنشانی** برای برگشت به پیش‌فرض `0.6s` استفاده کن. پنل کد با `duration` زنده هم‌گام می‌ماند.

## پارامترها

| پارامتر | نقش در این دمو |
| --- | --- |
| `duration` | ثانیه برای tween (پیش‌فرض‌های `0.2` / `0.6` / `1.6`) |
| فاصله (`x: 240`) | ثابت نگه داشته شده تا مدت تنها متغیر باشد |
| `ease: "none"` | زمان خطی — زمان‌بندی را از ایزینگ جدا می‌کند |

## مثال‌های عملی

۱. **فشردن دکمه / تاگل** — حدود 0.15–0.25s. کاربر منتظر ادامه است؛ زمان‌بندی بلند شکسته حس می‌شود.
۲. **ورود پنل / دراور** — حدود 0.35–0.55s. حضور کافی برای خواندن حرکت؛ هنوز برای استفاده تکراری تند.
۳. **اوربیت محصول هیرو یا نشست دوربین** — حدود 1.2–2s. نزدیک سینما؛ مدت وزن و توجه را می‌فروشد.
۴. **حلقه جوی (مه، درخشش بی‌کار)** — اغلب 3s+ یا پیوسته. زمان‌بندی بافت می‌شود، نه پیام یک‌شات.

ابتدای اکتشافی (نه قانون):

۱. **ورود** کمی بلندتر از **خروج** — با حضور بیا، تمیز برو.
۲. جابه‌جایی‌های فضایی بزرگ به زمان بیشتری از تلنگرهای کوچک نیاز دارند.
۳. آشکارسازی‌های مهم بیشتر از حرکت تزئینی زمان می‌خواهند.
۴. اگر کاربر روی تعامل قفل است، زمان‌بندی کوتاه‌تر را ترجیح بده.

## پیاده‌سازی

ساده‌ترین ابزار درست برای این درس: **GSAP** با ایز خطی تا مدت تنها متغیر باشد.

```js
gsap.to(".element", {
  x: 300,
  duration: 1.2, // زمان‌بندی اول اینجا زندگی می‌کند
  ease: "none", // فعلاً ایزینگ را نادیده بگیر — فقط مدت را حس کن
});
```

CSS همان ایده را آموزش می‌دهد (`transition-duration`)، ولی صحنه قابل‌پخش دوباره با کروم مشترک playground مقایسه کنار هم را آسان‌تر می‌کند — از همین‌رو GSAP در دمو آزمایشگاه.

## نکات کارایی

- خود مدت ارزان است؛ هزینه چیزی است که متحرک می‌کنی (layout thrash، فیلتر، DOM بزرگ، حلقه‌های پیوسته).
- وقتی حرکت مکرر است، ترنسفورم `x` / `y` / `scale` / `opacity` را بر ویژگی‌های layout ترجیح بده.
- tweenها را هنگام unmount بکش یا کامل کن (playground از پاک‌سازی `useGSAP` استفاده می‌کند).
- `prefers-reduced-motion` را رعایت کن: playground زمان‌بندی وقتی آن ترجیح روشن است به نمودار ایستای شروع→پایان عوض می‌شود؛ UI تولیدی باید همین یا کوتاه‌کردن حرکت را انجام دهد.

## خطاهای رایج

- تزئین با ایزینگ قبل از درست‌شدن حس مدت
- یک مدت «جادویی» برای هر رویداد UI
- سینمایی‌کردن تعامل‌های انتظار (کاربر تأخیر حس می‌کند، نه مهارت)
- عوض‌کردن هم‌زمان فاصله و مدت هنگام یادگیری — دیگر نمی‌فهمی کدام متغیر حس را ساخت

## کی استفاده کنی / نکنی

**زمان‌بندی عمدی استفاده کن وقتی:**

- مخاطب باید تغییر را *بخواند*
- وزن، اهمیت یا ضرب روایی به مدت بستگی دارد
- در حال ساخت زبان حرکت برای محصول یا توالی هستی

**از زمان‌بندی بلند پرهیز کن وقتی:**

- کاربر وسط کار منتظر تمام‌شدن حرکت است
- تغییر فقط کروم تأییدی است (توست، تاگل ریز)
- دسترس‌پذیری یا ترجیح حرکت کمتر حداقل حرکت می‌خواهد

## نکات کلیدی

- زمان‌بندی = مدت عمل؛ قبل از ایزینگ مسلط شو.
- همان مسیر + ساعت‌های متفاوت = احساس متفاوت.
- وب خلاقانه از سینما *و* UI قرض می‌گیرد — ساعتی را انتخاب کن که با کار جور باشد.
- فاصله و ایزینگ را ثابت نگه دار تا چشم را روی مدت آموزش دهی.
