# فاصله‌گذاری

## اول ببین

<SpacingPlayground />

فاصله‌گذاری فاصله بین موقعیت‌های پیاپی است. موقعیت‌های جمع یعنی حرکت کند؛ موقعیت‌های کشیده یعنی حرکت سریع.

## مقدمه

اگر زمان‌بندی مدت کل باشد و ایزینگ منحنی، **فاصله‌گذاری** چیزی است که وقتی هر فریم را منجمد کنی و شکاف‌ها را ببینی می‌بینی.

## چرا مهم است

انیماتورها حرکت را از طریق فاصله‌گذاری تشخیص می‌دهند. حرکتی می‌تواند مدت درست داشته باشد ولی فاصله‌گذاری غلط — شناور، تند یا مکانیکی حس شود.

## خواندن فاصله‌گذاری

| الگو | معنا |
|---|---|
| شکاف‌های یکنواخت | سرعت ثابت |
| شکاف‌ها بزرگ می‌شوند | شتاب |
| شکاف‌ها کوچک می‌شوند | کاهش سرعت |
| جمع در هر دو سر | Ease-in-out |
| یک شکاف بزرگ | اسنپ یا برش شبیه تله‌پورت |

## پارامترها

| پارامتر | اثر |
|---|---|
| نرخ فریم | نمونه‌های بیشتر فاصله‌گذاری را واضح‌تر نشان می‌دهد |
| منحنی ایز | توزیع فاصله‌گذاری را کنترل می‌کند |
| فاصله | سفر بزرگ‌تر شکاف‌ها را اغراق می‌کند |
| محو حرکت/شبح | در پخش نهایی فاصله‌گذاری را کمک یا پنهان می‌کند |

## کاربردهای عملی

- دراور UI: فاصله‌گذاری هنگام نشست باید جمع شود.
- جسم در حال سقوط: شکاف‌ها به‌سمت پایین بزرگ می‌شوند.
- هل دوربین: تغییر فاصله‌گذاری حس شتاب می‌سازد.
- انیمیشن اسپرایت/فریم: فاصله‌گذاری لفظاً پوز به پوز نوشته می‌شود.

## پیاده‌سازی

در GSAP، ایزینگ فاصله‌گذاری می‌سازد. برای بازرسی، موقعیت‌ها را در بازه‌های زمانی ثابت نمونه‌برداری کن نه اینکه به نام منحنی اعتماد کنی.

```ts
for (let t = 0; t <= 1; t += 0.1) {
  console.log(t, gsap.parseEase("power2.out")(t));
}
```

## خطاهای رایج

- انتخاب ایزینگ با نام بدون دیدن موقعیت‌ها
- افزودن محو حرکت برای پنهان‌کردن فاصله‌گذاری شکسته همه‌جا
- فرض اینکه حرکت آهسته خودکار یعنی فاصله‌گذاری جمع در جای درست

## کی استفاده کنی / نکنی

تحلیل فاصله‌گذاری را وقتی حرکت غلط حس می‌شود ولی مدت درست به‌نظر می‌رسد استفاده کن. در UI ساده، یک ease-out استاندارد اغلب کافی است.

## نکات کلیدی

- فاصله‌گذاری شتاب مرئی است.
- ایزینگ تولیدکننده فاصله‌گذاری است.
- با فریم‌های منجمد/پوست پیازی تشخیص بده.
