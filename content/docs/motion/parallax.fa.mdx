# پارالاکس

## اول ببین

<ParallaxPlayground />

یک مقدار پیشرفت را جابه‌جا کن. لایه‌های نزدیک بیشتر می‌روند؛ لایه‌های دور کمتر. دستگاه بصری‌ات آن تفاوت را عمق تفسیر می‌کند.

## مقدمه

**پارالاکس** جابه‌جایی ظاهری اشیای با فاصله‌های مختلف هنگام تغییر نقطه دید است. در وب با حرکت لایه‌ها با نرخ‌های متفاوت از اسکرول، اشاره‌گر یا پیشرفت دوربین شبیه‌سازی می‌شود.

## چرا مهم است

پارالاکس بدون سه‌بعدی کامل عمق می‌افزاید. می‌تواند هیرو را فضایی کند و داستان‌های اسکرولی را شبیه سفر دوربین حس کند. همچنین می‌تواند ناراحتی و نویز بصری بسازد.

## مدل لایه

| لایه | مقدار حرکت | ویژگی‌های بصری |
|---|---|---|
| پیش‌زمینه | بزرگ‌ترین | بزرگ‌تر، سریع‌تر، گاهی محو/بریده‌شده |
| میان‌زمینه/سوژه | متوسط | تمرکز اصلی، حرکت معتدل |
| پس‌زمینه | کوچک‌ترین | کندتر، کنتراست کمتر |

## پارامترها

| پارامتر | اثر |
|---|---|
| نسبت دامنه | قدرت عمق |
| منبع پیشرفت | اسکرول، ماوس، درگ، تایم‌لاین |
| جهت | لایه‌ها معمولاً با منطق نقطه دید هم‌خوان حرکت می‌کنند |
| برش (Clipping) | عناصر پیش‌زمینه به فضای overflow نیاز دارند |
| محو/مقیاس | عمق را تقویت می‌کند ولی هزینه کارایی دارد |

## کاربردهای عملی

۱. **هیرو:** افق شهر پس‌زمینه کند، محصول متوسط، شکل پیش‌زمینه سریع.
۲. **داستان اسکرولی:** لایه‌ها دالی/تراک را شبیه‌سازی می‌کنند.
۳. **بازی/منو:** پارالاکس اشاره‌گر برای عمق ظریف.
۴. **محصول:** محیط کمتر از محصول هنگام اسکرول شبیه اوربیت حرکت می‌کند.

## پیاده‌سازی

```ts
const setLayers = (p: number) => {
  gsap.set(".far", { x: p * 20 });
  gsap.set(".mid", { x: p * 55 });
  gsap.set(".near", { x: p * 110 });
};
```

ترنسفورم را ترجیح بده و `will-change` را فقط جایی که توجیه دارد استفاده کن.

## خطاهای رایج

- هر بخش با جهت پارالاکس متفاوت
- پارالاکس اشاره‌گر روی صفحه‌های متن‌سنگین
- دامنه‌هایی آن‌قدر بزرگ که شکاف layout ظاهر شود
- حرکت پس‌زمینه را دالی واقعی دوربین نامیدن

## کارایی و دسترس‌پذیری

پارالاکس می‌تواند ناراحتی دهلیزی ایجاد کند. حرکت کاهش‌یافته را رعایت کن، دامنه‌ها را معتدل نگه دار و خارج از صفحه مکث کن. محتوا را فقط از طریق موقعیت‌های پارالاکس دسترس‌پذیر نکن.

## کی استفاده کنی / نکنی

برای هیرو و صحنه‌های روایی استفاده کن. از فرم، داک، داشبورد و پرداخت پرهیز کن.

## نکات کلیدی

- سرعت افتراقی = عمق ادراکی.
- نزدیک بیشتر از دور حرکت می‌کند.
- پارالاکس شبیه‌سازی است، نه حرکت فضایی واقعی دوربین.
