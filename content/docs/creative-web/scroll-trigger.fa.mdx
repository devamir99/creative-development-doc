# ScrollTrigger، انیمیشن اسکرول‌محور و پین

## اول ببین

<ScrollProgressPlayground />

داخل صحنه اسکرول کن. خروجی مهم نوار اسکرول نیست؛ `progress` نرمال‌شده از 0 تا 1 است.

## مقدمه

GSAP ScrollTrigger انیمیشن را به موقعیت اسکرول وصل می‌کند. می‌تواند هنگام ورود پخش کند، وضعیت‌ها را تاگل کند، تایم‌لاین را scrub کند، بخش را پین کند، و پیشرفت را گزارش دهد.

## مفاهیم هسته

| مفهوم | معنا |
|---|---|
| Trigger | عنصری که موقعیتش رفتار را شروع می‌کند |
| Start/end | موقعیت‌های اسکرول که بازه فعال را تعریف می‌کنند |
| Scrub | پیشرفت تایم‌لاین از اسکرول پیروی می‌کند |
| Pin | بخش ویوپورت در یک بازه اسکرول ثابت می‌ماند |
| Toggle actions | پخش/برگشت و غیره در مرزها |
| Progress | مقدار نرمال‌شده 0..1 |
| Refresh | محاسبه دوباره پس از تغییر layout/دارایی‌ها |

## چرا مهم است

ScrollTrigger طول صفحه را به تایم‌لاین تبدیل می‌کند. پل میان صفحات تحریری و سیستم‌های سینمایی دوربین/حرکت است.

## پارامترها

| پارامتر | اثر |
|---|---|
| `start` / `end` | شروع/پایان فصل |
| `scrub` | پیوند مستقیم یا catch-up نرم |
| `pin` | مدت صحنه ثابت |
| `anticipatePin` | پرش پین را کم می‌کند |
| `markers` | فقط دیباگ؛ در production حذف کن |
| `invalidateOnRefresh` | پس از resize مقادیر را دوباره بساز |

## کاربردهای عملی

۱. **چرخش محصول:** اوربیت را روی هیروی پین‌شده scrub کن.
۲. **ساخت نمودار:** پیشرفت خط‌ها/میله‌ها را می‌کشد.
۳. **آشکارسازی فصل:** تایم‌لاین هنگام ورود پخش می‌شود، بدون پین.
۴. **اسکرول افقی:** پیشرفت عمودی یک ترک را جابه‌جا می‌کند.

## پیاده‌سازی

```ts
gsap.to(".product", {
  rotateY: 360,
  ease: "none",
  scrollTrigger: {
    trigger: ".chapter",
    start: "top top",
    end: "+=120%",
    scrub: true,
    pin: true,
  },
});
```

در React، داخل context محدود GSAP بساز و پاک‌سازی کن.

## خطاهای رایج

- پین بدون درک layout موبایل
- markers که هنوز دیده می‌شوند
- ساخت ScrollTrigger قبل از اینکه فونت/تصاویر layout را پایدار کنند
- چند بخش پین‌شده که با هم می‌جنگند
- انیمیشن‌هایی که فقط بعد از بارگذاری جاوااسکریپت کار می‌کنند و محتوا نامرئی است

## کارایی و دسترس‌پذیری

محتوا را بدون پین خوانا نگه دار. حرکت کاهش‌یافته را رعایت کن، ناوبری کیبورد را تست کن، و صحنه‌های سنگین را وقتی خارج از صفحه‌اند pause کن.

## کی استفاده کنی / نکنی

برای فصل‌های روایی و داستان محصول استفاده کن. در مستندات، فرم‌ها، checkout و ابزارهای فشرده پرهیز کن.

## نکات کلیدی

- ScrollTrigger بازه اسکرول را به پیشرفت انیمیشن نگاشت می‌کند.
- پین زمان می‌خرد اما کنترل کاربر را هزینه می‌کند.
- Refresh/پاک‌سازی الزامات production هستند.
