# تایم‌لاین‌های GSAP و مبانی وب خلاقانه

## اول ببین

<TimelinePlayground />

تایم‌لاین چند انیمیشن بی‌ربط نیست. یک توالی تألیف‌شده با ضرب، برچسب، هم‌پوشانی و یک ساعت اصلی است.

## مقدمه

GSAP ویژگی‌ها را در زمان متحرک می‌کند. یک **تویین** (tween) یک تغییر است. یک **تایم‌لاین** (timeline) تویین‌ها را پشت‌سرهم و هم‌پوشان می‌چیند. ScrollTrigger می‌تواند تایم‌لاین را به‌جای زمان با اسکرول براند.

## واژگان هسته

| API/مفهوم | معنا |
|---|---|
| `gsap.to` | متحرک‌سازی تا مقادیر |
| `gsap.from` | متحرک‌سازی از مقادیر (مراقب بارگذاری/FOUC باش) |
| `gsap.fromTo` | شروع/پایان صریح |
| `gsap.timeline` | توالی/هم‌پوشانی تویین‌ها |
| Label | موقعیت زمانی نام‌دار |
| Position parameter | جای‌گذاری مطلق/نسبی در تایم‌لاین |
| `defaults` | مدت/ایزینگ مشترک |
| `useGSAP` | محدوده‌بندی و پاک‌سازی React در این پروژه |

## چرا مهم است

وب‌سایت‌های خلاقانه به رقص‌پردازی نیاز دارند: تیتر، رسانه، دوربین، UI و گذارها باید زمان‌بندی مشترک داشته باشند. انیمیشن‌های CSS مستقل از هم فاصله می‌گیرند.

## پارامترها

| پارامتر | اثر |
|---|---|
| Duration | طول ضرب |
| Ease | شخصیت حرکت |
| Delay/position | رابطه توالی |
| Stagger | ریتم تکرار |
| Repeat/yoyo | حلقه و برگشت |
| TimeScale | سرعت کل توالی |

## کاربردهای عملی

۱. **ورود هیرو:** آشکارسازی ماسک → کلمات تیتر → محصول → CTA.
۲. **گذار صفحه:** پوشش → تعویض مسیر → آشکارسازی.
۳. **فصل اسکرول:** یک تایم‌لاین که ScrollTrigger آن را scrub می‌کند.
۴. **پیکربند محصول:** قطعات در گام‌های برچسب‌دار سرهم می‌شوند.

## پیاده‌سازی

```ts
const tl = gsap.timeline({ defaults: { ease: "power3.out" } });
tl.from(".media", { scale: 1.15, duration: .8 })
  .from(".word", { y: 50, stagger: .06, duration: .55 }, "-=0.45")
  .from(".cta", { autoAlpha: 0, y: 16, duration: .35 }, "-=0.2");
```

در React، انیمیشن‌ها را محدود کن و هنگام unmount برگردان.

## خطاهای رایج

- متحرک‌سازی از حالت‌هایی که محتوای بدون‌استایل را چشمک می‌زنند
- ساخت تایم‌لاین در هر رندر
- فراموشی پاک‌سازی در React
- تایم‌لاین‌های تو در تو با مدت master نامشخص
- استفاده از GSAP برای hover ساده‌ای که CSS بهتر انجام می‌دهد

## کارایی

`transform`/`opacity` را ترجیح بده، از متحرک‌سازی زیاد ویژگی‌های layout پرهیز کن، و تایم‌لاین‌های خارج از صفحه را pause کن.

## کی استفاده کنی / نکنی

GSAP را برای توالی، اسکرول و تعامل پیچیده استفاده کن. جایی که یک transition CSS ساده‌تر و ایزوله است، پرهیز کن.

## نکات کلیدی

- تویین = تغییر؛ تایم‌لاین = رقص‌پردازی.
- برچسب‌ها توالی‌ها را قابل‌نگهداری می‌کنند.
- پاک‌سازی React اجباری است.
