# داستان‌گویی اسکرولی و گذارهای روایی

## اول ببین

<ScrollProgressPlayground />

اسکرول دست خواننده را روی پروژکتور می‌گذارد. طراح همچنان توالی، تأکید و مرز فصل‌ها را کنترل می‌کند.

## مقدمه

داستان‌گویی اسکرولی (Scroll Storytelling) ضربه‌های روایی را در طول یک صفحه می‌چیند. با تغییر پیشرفت، رسانه، تایپ، دوربین، داده یا صحنه‌ها دگرگون می‌شوند.

## ساختارهای روایی

| ساختار | کاربرد |
|---|---|
| سفر خطی | ساخت محصول، سفر، فرایند |
| آشکارسازی فصلی | بخش‌های مطالعه موردی |
| مقایسه | قبل/بعد، مسئله/راه‌حل |
| سفر نقشه/خط زمانی | تاریخ، داده، جغرافیا |
| بازرسی شیء | ویژگی‌های محصول به‌ترتیب |
| ساخت موازی | لایه‌ها سرهم می‌شوند تا سیستم نهایی ساخته شود |

## چرا مهم است

اسکرول آشناست، قابل اشتراک‌گذاری است و بدون آنکه از کاربران بخواهد رابط تازه‌ای یاد بگیرند کار می‌کند. می‌تواند سینما، طراحی تحریریه، داده و تعامل را با هم ترکیب کند.

## پارامترها

| پارامتر | اثر |
|---|---|
| طول فصل | زمان خواندن و حرکت |
| مدت پین‌شدن | چقدر نمای دید با یک صحنه می‌ماند |
| نگاشت پیشرفت | مستقیم، ایزشده، پلکانی یا آستانه‌ای |
| نوع گذار | برش، محو، پاک‌کردن، حرکت دوربین، مورف |
| جای زیرنویس | نباید با نقطه کانونی بصری بجنگد |

## کاربردهای عملی

۱. **محصول:** با اسکرول محصول می‌چرخد و ویژگی‌ها ظاهر می‌شوند.
۲. **گزارش:** نمودارها هم‌زمان با پیش‌رفتن استدلال ساخته می‌شوند.
۳. **مطالعه موردی:** دوربین از مسئله به نتیجه تراک می‌کند.
۴. **تاریخ:** خط زمانی در دوره‌ها پیش می‌رود.

## پیاده‌سازی

فصل‌ها را اول به‌صورت بخش‌های معنایی بساز. پین‌کردن/اسکراب را فقط وقتی اضافه کن که صفحه به‌صورت محتوای معمولی کار کند.

```ts
ScrollTrigger.create({
  trigger: chapter,
  start: "top top",
  end: "+=120%",
  scrub: true,
  pin: true,
});
```

## خطاهای رایج

- پین‌کردن همه‌چیز
- متن خیلی کوچک یا متحرک هنگام خواندن
- فاصله اسکرولی بسیار طولانی‌تر از ارزش اطلاعات
- چیدمان موبایلی که بدون بازطراحی از پین‌کردن دسکتاپ کپی شده است
- نبود راهی برای ردکردن یا بازدید دوباره فصل‌ها

## کارایی و دسترس‌پذیری

جایگزین بدون پین، حالت reduced-motion، محتوای قابل دسترس با صفحه‌کلید و هرجا مفید است نشانگر پیشرفتِ دیده‌شدنی بده. وقتی WebGL خارج از صفحه است، آن را متوقف کن.

## کی استفاده کنی / نکنی

برای بازاریابی روایی، توضیح‌دهنده‌ها، پورتفولیوها و گزارش‌ها استفاده کن. برای پرداخت، تنظیمات، مرجع مستندات و کارهای فوری پرهیز کن.

## نکات کلیدی

- اسکرول زمان را کنترل می‌کند، نه فقط موقعیت را.
- فصل‌ها به وعده و نتیجه‌گیری نیاز دارند.
- صفحه خوانای بدون پین، بنیان کار است.
