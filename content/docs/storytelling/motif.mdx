# Motif & Continuity

## See it first

Three scenes. Keep **Motif on** — the yellow circle returns in a new role each time. Turn it **off** — the scenes feel unrelated. Watch first; read later.

<MotifPlayground />

## Introduction

A **motif** is a recurring shape, color, or motion that accrues meaning. **Continuity** keeps space readable so motifs can accumulate.

## Why it matters

- Brands become recognizable through motifs, not one-off tricks.
- Breaking continuity is fine when the break *is* the message.

## Visual explanation

| Idea | In the demo |
| --- | --- |
| Shape motif | Same circle, new job each scene |
| Continuity | Shared accent across cuts |
| Broken motif | Motif off → no shared character |

## Key takeaways

- Motifs bind; continuity carries.
- Repeat with variation, not clone spam.
