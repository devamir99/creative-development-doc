# Motif & Continuity

## Introduction

A **motif** is a recurring shape, color, motion, or sound that accrues meaning. **Continuity** keeps space and time believable across cuts so motifs can accumulate instead of resetting the viewer.

## Why it matters

- Brands become recognizable through motifs, not one-off hero tricks.
- Breaking continuity is fine when the break *is* the message.

## Visual explanation

| Idea | Example |
| --- | --- |
| Shape motif | Circle → logo → aperture wipe |
| Color motif | Accent yellow returns on every CTA |
| Motion motif | Same anticipation curve on every chapter open |
| Continuity | Matching eyelines / screen direction across cuts |

## Practical examples

1. **Portfolio** — same horizontal wipe + accent each project.
2. **Product story** — silhouette motif from packaging → 3D hero.
3. **Docs** — recurring callout pattern as a “character.”

## Key takeaways

- Motifs bind; continuity carries.
- Repeat with variation, not clone spam.
