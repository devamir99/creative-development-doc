# لایه‌ها، عمق و مقیاس

## اول ببین

<LayersDepthPlayground />

عمق فقط سه‌بعدی نیست. هم‌پوشانی، مقیاس، کنتراست، وضوح و نرم‌شدن اتمسفری می‌توانند یک قاب تخت را لایه‌بندی کنند.

## مقدمه

ترکیب‌بندی لایه‌ای (Layers & Depth) قاب را به **پیش‌زمینه**، **میان‌زمینه** و **پس‌زمینه** جدا می‌کند. سوژه معمولاً در یک لایه زندگی می‌کند و لایه‌های دیگر زمینه، قاب‌بندی یا عمق می‌دهند.

## نشانه‌های عمق

| نشانه | چطور کار می‌کند |
|---|---|
| هم‌پوشانی | شیء جلو بخشی از شیء پشت را پنهان می‌کند |
| مقیاس نسبی | بزرگ‌تر معمولاً نزدیک‌تر خوانده می‌شود |
| موقعیت عمودی | در منظره‌ها بالاتر اغلب دورتر خوانده می‌شود |
| کنتراست/روشنایی | نزدیک اغلب قوی‌تر؛ دور ضعیف‌تر |
| وضوح | لایه فوکوس نزدیک‌تر/مهم‌تر خوانده می‌شود |
| اتمسفر | لایه‌های دور روشن/نرم می‌شوند |
| پارالاکس | لایه‌ها با نرخ‌های متفاوت حرکت می‌کنند |
| سایه | اشیا را در فضا زمین‌گیر می‌کند |

## چرا مهم است

ترکیب‌بندی‌های تخت می‌توانند حس برچسب بدهند. لایه‌ها جهان، مقیاس و مسیرهایی برای حرکت دوربین می‌سازند. در تجربه‌های اسکرولی، لایه‌ها به پارالاکس یا عمق سه‌بعدی واقعی تبدیل می‌شوند.

## پارامترها

| پارامتر | اثر |
|---|---|
| تعداد لایه‌ها | لایه بیشتر می‌تواند غنی کند یا شلوغ |
| جدایی | تفاوت‌های روشنایی/رنگ/فوکوس بین صفحه‌ها |
| قاب‌بندی پیش‌زمینه | حس نگاه‌کردن از میان چیزی می‌سازد |
| لایه سوژه | صمیمیت و زمینه را تعیین می‌کند |
| نرخ حرکت | در پارالاکس لایه‌های نزدیک سریع‌تر حرکت می‌کنند |

## کاربردهای عملی

1. **هیرو:** شکل پیش‌زمینه تار، محصول در میان‌زمینه، پس‌زمینه گرادیانی نرم.
2. **صحنه داستانی:** درگاه در پیش‌زمینه، شخصیت در میان‌زمینه، شهر در پس‌زمینه.
3. **پیکربندی محصول:** کف، محصول، محیط، اتمسفر.
4. **صفحه تحریریه‌ای:** تصویر، کپشن و تایپوگرافی پس‌زمینه به‌عنوان صفحه‌های جدا.

## پیاده‌سازی

```css
.foreground { z-index: 3; filter: blur(2px); }
.subject { z-index: 2; }
.background { z-index: 1; opacity: .7; }
```

در سه‌بعدی، از موقعیت‌های واقعی Z و پارالاکس دوربین استفاده کن. منطق لایه‌ها را معنایی نگه دار، نه عددهای دلبخواهی `z-index`.

## خطاهای رایج

- لکه‌های تزئینی پیش‌زمینه بدون داستان فضایی
- سوژه و پس‌زمینه با کنتراست/وضوح یکسان
- لایه‌های بیش از حد که برای توجه رقابت می‌کنند
- تفاوت‌های مقیاس که محصول را ناخواسته اسباب‌بازی‌مانند می‌کنند

## کارایی

لایه‌های بزرگ تار و چند تصویر تمام‌صفحه گران‌اند. دارایی‌های کوچک تار، گرادیان‌ها یا ترنسفورم‌های GPU را ترجیح بده.

## کی استفاده کنی / نکنی

برای جهان‌سازی و عمق سینمایی از لایه‌ها استفاده کن. در داشبوردها و فرم‌های متراکم از لایه‌بندی سنگین پرهیز کن.

## نکات کلیدی

- عمق مجموعه‌ای از نشانه‌هاست، نه فقط پرسپکتیو.
- پیش‌زمینه قاب می‌گیرد؛ میان‌زمینه عمل می‌کند؛ پس‌زمینه توضیح می‌دهد.
- مقیاس هم نشانه عمق است هم نشانه معنا.

## تمرین

یک هیروی تخت بردار. یک پیش‌زمینه اضافه کن، سوژه را در میان‌زمینه نگه دار و پس‌زمینه را نرم کن. توجه کن ادراک مقیاس چطور عوض می‌شود.
