# قانون یک‌سوم

## مقدمه

قاب را به یک شبکه 3×3 تقسیم کن. **تقاطع‌ها** (و خود خطوط) خانه‌های پیش‌فرض قدرتمندی برای سوژه‌ها هستند. این یک راهنمای تجربی (Rule of Thirds) است — برای شروع عالی، به‌عنوان جزم‌اندیشی ضعیف.

## چرا مهم است

- تصمیم‌های قاب‌بندی را سریع‌تر می‌کند.
- توضیح می‌دهد چرا مرکزِ مرده می‌تواند ایستا حس شود (و کی همان مطلوب است).
- به‌تمیزی روی موقعیت‌های درصدی در CSS و روکش‌های ترکیب‌بندی دوربین نگاشت می‌شود.

## توضیح بصری

شبکه زرد + نقطه‌ها نقاط قدرت کلاسیک را نشان می‌دهند. سوژه را روی آن‌ها پارک کن، بعد با مرکز مقایسه کن.

## پارامترها

| کنترل | نقش |
| --- | --- |
| X / Y | موقعیت نرمال‌شده سوژه |
| پیش‌فرض‌ها | بالا-چپ / بالا-راست / پایین-چپ / پایین-راست / مرکز |
| شبکه | روشن/خاموش کردن روکش آموزشی |

## کاربردهای عملی

1. **برش پرتره** — چشم‌ها نزدیک یک‌سوم بالایی.
2. **منظره** — افق روی یک‌سوم پایینی یا بالایی، نه وسط.
3. **حالت خالی رابط** — تصویرسازی روی یک نقطه یک‌سوم، متن در سمت مقابل.

## پیاده‌سازی

```js
const points = [
  [1 / 3, 1 / 3],
  [2 / 3, 1 / 3],
  [1 / 3, 2 / 3],
  [2 / 3, 2 / 3],
];
```

## نکات کارایی

- شبکه‌های روکش در رابط‌های تولیدی فقط برای اشکال‌زدایی‌اند.

## خطاهای رایج

- با یک‌سوم‌ها مثل قانون اجباری رفتار کردن
- نادیده گرفتن سوژه‌ای که *خودش* مرکز می‌خواهد (نشان‌ها، آیکون‌ها)
- هم‌تراز کردن همه عناصر با شبکه تا جایی که سفت و خشک حس شود

## کی استفاده کنی / نکنی

**استفاده کن** به‌عنوان گذر اول.
**پرهیز کن** وقتی تقارن یا مرکزیت نمادین، خودِ بریف است.

## نکات کلیدی

- یک‌سوم‌ها = پیش‌فرض مفید، نه حقیقت.
- برای بسیاری سوژه‌ها تقاطع‌ها از لبه‌ها بهترند.
- قانون را بعد از اینکه توانستی ببینیش، بشکن.
