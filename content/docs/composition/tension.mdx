# Tension

## Introduction

**Tension** is the feeling that something is unsettled — or about to happen. It comes from imbalance, edge pressure, tight gaps, and unfinished crops — used *on purpose*.

## Why it matters

- Stories need pressure before release.
- Scroll experiences often sequence calm → tension → reveal.
- Uncontrolled tension just looks like a layout bug.

## Visual explanation

Shrink the gap or pull masses toward the frame edge. Watch calm turn into pressure.

## Parameters

| Control | Role |
| --- | --- |
| Gap | Space between masses |
| Edge inset | How close the group sits to the frame |
| Mass count | More bodies → easier crowding |

## Practical examples

1. **Pre-CTA beat** — subject near edge; space asks for the button.
2. **Horror / thriller UI** — crop faces at the frame edge.
3. **Product teaser** — incomplete crop before the full hero.

## Implementation

Author tension with proximity and edge distance; release it by re-centering, increasing gap, or cutting to a new scene.

## Performance notes

- Pure layout — inexpensive.

## Common mistakes

- Permanent high tension with no release
- Crowding until type becomes unreadable
- Confusing clutter with tension

## When to use / avoid

**Use** before reveals and peaks.
**Avoid** on dense documentation screens that need calm scanning.

## Key takeaways

- Tension is controlled imbalance.
- Edge + gap are primary knobs.
- Release is part of the phrase.
