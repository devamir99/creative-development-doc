# Symmetry & Visual Hierarchy

## See it first

<SymmetryPlayground />

Symmetry creates ceremony. Hierarchy creates order of reading. A frame can be symmetrical but still need one first thing to see.

## Introduction

**Symmetry** balances similar elements around an axis. **Visual hierarchy** ranks information so the viewer knows what to read first, second, and last.

## Symmetry types

| Type | Feeling | Use |
|---|---|---|
| Bilateral | Formal, calm, iconic | Logos, architecture, rituals |
| Radial | Orbit, focus, mandala | Diagrams, loaders, emblems |
| Approximate | Ordered but alive | Editorial layouts |
| Broken symmetry | Tension, story event | One element violates the pattern |

## Hierarchy tools

1. Size and scale
2. Contrast and color
3. Position and isolation
4. Sharpness/focus
5. Motion (use carefully; moving things win)
6. Typography weight and spacing

## Why it matters

Without hierarchy, everything shouts. Without some order, hierarchy can feel chaotic. Most strong frames combine a clear first read with a deliberate second read.

## Visual explanation

Ask three questions: What do I see first? Where do I go next? Where do I rest? If answers are accidental, hierarchy is not designed.

## Parameters

| Parameter | Hierarchy effect |
|---|---|
| Scale ratio | Bigger differences create clearer rank |
| Accent count | More accents weaken each accent |
| Whitespace grouping | proximity creates categories |
| Motion | Animated element jumps the queue |

## Practical applications

1. **Landing:** headline first, product second, CTA third — or product first if visual brand leads.
2. **Pricing:** symmetrical columns, one highlighted plan breaks symmetry.
3. **Docs:** title, summary, code, note in predictable rank.
4. **Ceremony/brand mark:** strict symmetry creates icon status.

## Implementation

Write hierarchy in content order before styling. Use semantic headings and DOM order; visual rank should not fight accessibility order.

## Common mistakes

- Everything bold, bright, and animated
- Perfect symmetry where story needs tension
- Visual hierarchy that differs from screen-reader order
- Highlighting multiple plans/buttons as “primary”

## When to use / avoid

Use symmetry for formality and icons. Use broken symmetry for narrative. Avoid visual tricks that make important content appear later to assistive technology.

## Key takeaways

- Symmetry is spatial order.
- Hierarchy is reading order.
- One primary accent is stronger than five.
