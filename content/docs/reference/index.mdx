## Production checklist (any creative page)

- [ ] One clear focal point per beat
- [ ] Camera move motivated (reveal / follow / inspect)
- [ ] Cut or transition chosen deliberately
- [ ] Duration + ease named, not accidental
- [ ] Reduced-motion path works
- [ ] Keyboard/touch alternative for 3D hotspots
- [ ] DPR, shadows, and post effects budgeted
- [ ] Content readable without JavaScript pinning
- [ ] Accent and motion verbs consistent with visual language
