# برگه تقلب خلاقانه

## می‌خواهم…

| هدف | برو سراغ | پرهیز کن از |
|---|---|---|
| نشان بده کجا هستیم | Extreme wide / wide | اول close-up |
| نشان بده احساس/جزئیات | Close-up | Wide با سوژه ریز |
| سوژه را قدرتمند کن | Low angle | High angle |
| سوژه را آسیب‌پذیر کن | High angle | Low angle |
| صمیمی نزدیک شو | Dolly in | زوم FOV که وانمود کند دالی است |
| محصول را بازرسی کن | Orbit، FOV ثابت | دوربین آزاد تصادفی |
| یک صفحه عمق را انتخاب کن | DOF / rack focus | تار کردن همه‌چیز |
| صحنه را تمیز عوض کن | Hard cut | Dissolve همه‌جا |
| زمان/خاطره را نرم کن | Dissolve | Wipe تند |
| با صدای بعدی شروع کن | J-cut | — |
| صدا را زیر تصویر جدید نگه دار | L-cut | — |
| کنش موازی را فشرده کن | Cross-cutting | یک صحنه بلند بدون برش |
| یک چیز برنده شود | ابزارهای نقطه کانونی | پنج لهجه همزمان |
| حس آرامش/لوکس | فضای منفی | شلوغی |
| چشم را به سوژه ببر | خطوط هدایت‌کننده | خطوطی که از قاب خارج می‌شوند |
| عمق ارزان بفروش | لایه‌های پارالاکس | سرعت لایه‌ها برعکس |
| ورود UI | Ease-out، 200–500ms | Bounce |
| رها کردن درگ | Spring با damping | نوسان کشسان بلند |
| ورود چند آیتم | Stagger 40–90ms | 300ms × 20 آیتم |
| حال‌وهوای محصول | نورپردازی سه‌نقطه‌ای | فقط ambient تخت |
| اتمسفر شب | Fog + bloom مهارشده | Bloom روی همه‌چیز |
| داستان اسکرولی | ScrollTrigger scrub | پین کردن هر بخش |
| انتخاب سه‌بعدی | Raycast + لیست DOM | هات‌اسپات فقط با hover |
| سطح امضای GPU | ShaderMaterial | شیدر روی متن بدنه |

## نقاط شروع مدت

| حرکت | از اینجا شروع کن |
|---|---|
| بازخورد دکمه/تاگل | 120–250ms |
| پنل/کشویی | 300–550ms |
| مجموع stagger لیست | زیر ~800ms |
| آشکارسازی هیرو | 900–1800ms |
| بیت دالی/اوربیت دوربین | 1200–2500ms |
| گذار صفحه cover+reveal | 600–1200ms جمع |

این‌ها نقطه شروع‌اند، نه قانون. لحن محصول و تنظیمات reduced-motion بر آن‌ها اولویت دارند.

## نقاط شروع ایزینگ

| کار | خانواده ایزینگ |
|---|---|
| ورود | `power3.out` / ease-out |
| خروج | `power2.in` (کوتاه‌تر از ورود) |
| جابه‌جایی بین حالت‌ها | `power2.inOut` |
| مکانیکی/ثابت | `none` |
| ضربه بازیگوش | `back.out(1.4)` به‌ندرت |
| فرود فیزیکی | Spring / `elastic.out` به‌ندرت |

## نقد ده‌ثانیه‌ای

۱. اول چه می‌بینم؟
۲. چشم کجا آرام می‌گیرد؟
۳. چه چیزی عوض شد و چرا الان؟
۴. دوربین در فضا حرکت می‌کند یا فقط زوم می‌کند؟
۵. برش/گذار سبکش را توجیه می‌کند؟
۶. گرم یا سرد — و عمدی است؟
۷. اولین فعل حرکت چیست؟
۸. با حرکت کاهش‌یافته می‌توانم بخوانم/استفاده کنم؟
۹. روی موبایل میان‌رده چقدر هزینه دارد؟
۱۰. یک تغییر که بیشترین کمک را می‌کند چیست؟
