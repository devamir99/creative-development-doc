# Glossary

Use this page as the Lab's dictionary. Each term links to the lesson that teaches it in depth.

| Term | One-line definition | Lesson |
|---|---|---|
| Shot size | How much subject/environment is framed | [Shot Types](../camera/shot-types.mdx) |

| FOV | Angular width of the camera's vision | [FOV](../camera/fov.mdx) |
| Dolly | Camera physically moves forward/back | [Dolly vs Zoom](../camera/dolly-zoom.mdx) |
| Zoom | Lens/FOV change without moving the eye | [Dolly vs Zoom](../camera/dolly-zoom.mdx) |
| Orbit | Camera arcs around a look-at target | [Orbit](../camera/orbit.mdx) |
| DOF | Depth range that appears sharp | [DOF](../camera/dof.mdx) |

| Frustum | Pyramid/box volume a camera can see | [Projection](../camera/projection.mdx) |
