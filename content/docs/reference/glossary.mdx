# Glossary

Use this page as the Lab's dictionary. Each term links to the lesson that teaches it in depth.

## Camera

| Term | One-line definition | Lesson |
|---|---|---|
| Shot size | How much subject/environment is framed | [Shot Types](/docs/camera/shot-types) |
| Angle | Vertical power relationship of camera to subject | [Shot Types](/docs/camera/shot-types) |
| FOV | Angular width of the camera's vision | [FOV](/docs/camera/fov) |
| Dolly | Camera physically moves forward/back | [Dolly vs Zoom](/docs/camera/dolly-zoom) |
| Zoom | Lens/FOV change without moving the eye | [Dolly vs Zoom](/docs/camera/dolly-zoom) |
| Orbit | Camera arcs around a look-at target | [Orbit](/docs/camera/orbit) |
| DOF | Depth range that appears sharp | [DOF](/docs/camera/dof) |
| Rack focus | Focus distance changes during a shot | [DOF](/docs/camera/dof) |
| Frustum | Pyramid/box volume a camera can see | [Projection](/docs/camera/projection) |
| Orthographic | Projection with no distance scaling | [Projection](/docs/camera/projection) |
| Parallax (camera) | Near/far shift proving spatial movement | [Movement](/docs/camera/movement) |
