# مرجع

این صفحات را هنگام کار واقعی باز نگه دارید.

- [واژه‌نامه](./glossary): هر اصطلاح اصلی در یک خط، با پیوند به درس کامل.
- [برگه تقلب خلاقانه](./cheat-sheet): جداول تصمیم برای انتخاب نما، برش، ایزینگ، نور و تکنیک.
- [چرخه نقد](../direction/critique): روش بازبینی ده‌ثانیه‌ای.

## چک‌لیست تولید (هر صفحه خلاقانه)

- [ ] یک نقطه کانونی واضح در هر بیت
- [ ] حرکت دوربین با انگیزه (آشکارسازی / دنبال‌کردن / بازرسی)
- [ ] برش یا گذار عمداً انتخاب شده
- [ ] مدت و ایزینگ نام‌گذاری‌شده، نه اتفاقی
- [ ] مسیر reduced-motion کار می‌کند
- [ ] جایگزین صفحه‌کلید/لمسی برای هات‌اسپات‌های سه‌بعدی
- [ ] بودجه DPR، سایه‌ها و افکت‌های پس‌پردازش مشخص است
- [ ] محتوا بدون پین جاوااسکریپت خوانا می‌ماند
- [ ] لهجه و افعال حرکت با زبان بصری هم‌خوان‌اند
