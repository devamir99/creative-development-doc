# انواع نور و سایه‌ها

## اول ببین

<LightTypesPlayground />

این زمین بازی استعاره‌ای با CSS است. در صحنه سه‌بعدی واقعی، هر نوع نور هندسه، افت نوری، هزینه و قواعد سایه خودش را دارد.

## انواع نور

| نوع | تشبیه دنیای واقعی | رفتار | کاربرد معمول |
|---|---|---|---|
| محیطی (Ambient) | بازتاب عمومی | همه‌چیز را پر می‌کند، بدون جهت | دیده‌شدن پایه |
| نیم‌کره‌ای (Hemisphere) | بازتاب آسمان + زمین | پرکننده ملایم دورنگه | فضای بیرونی |
| جهت‌دار (Directional) | خورشید | پرتوهای موازی، موقعیت = جهت | نور روز، نور اصلی |
| نقطه‌ای (Point) | لامپ | از یک نقطه پخش می‌شود، افت می‌کند | چراغ‌ها، جرقه‌ها |
| موضعی (Spot) | نورافکن صحنه | مخروط با angle/penumbra | تمرکز، صحنه، چراغ‌قوه |
| ناحیه مستطیلی (Rect area) | سافت‌باکس/پنجره | نور نرم پهن (وابسته به رندرر) | محصول، داخلی |

## اصول سایه

- جهت سایه، جهت نور را آشکار می‌کند.
- سایه‌های سخت منابع کوچک/مستقیم را القا می‌کنند؛ سایه‌های نرم منابع بزرگ/پخش‌شده را.
- سایه‌های تماس اشیا را روی زمین می‌نشانند.
- نورهای سایه‌ساز زیاد پرهزینه‌اند.
- نقشه‌های سایه به تنظیم bias نیاز دارند تا از acne/peter-panning پرهیز شود.

## چرا مهم است

نوع نور فرم، حال‌وهوا و کارایی را تعیین می‌کند. شیئی واقع‌گرایانه با جهت سایه اشتباه بلافاصله جعلی حس می‌شود.

## پارامترها

| پارامتر | اثر |
|---|---|
| شدت | سهم نوردهی |
| رنگ/دما | حال‌وهوا و زمان |
| فاصله/افت | افت نور نقطه‌ای/موضعی |
| Angle/penumbra | مخروط موضعی و نرمی لبه |
| اندازه نقشه سایه | تیزی در برابر حافظه/هزینه |
| Cast/receive | کدام اشیا سایه می‌سازند/می‌خوانند |

## کاربردهای عملی

۱. **محصول:** نور اصلی جهت‌دار + پرکننده نیم‌کره‌ای + لهجه موضعی.
۲. **اتاق بازی:** چراغ‌های نقطه‌ای با فاصله محدود.
۳. **بیرونی:** یک خورشید جهت‌دار با سایه، آسمان نیم‌کره‌ای.
۴. **سه‌بعدی رابط کاربری:** سایه تماس جعلی ممکن است ارزان‌تر از نقشه‌های سایه واقعی باشد.

## پیاده‌سازی (R3F)

```tsx
<ambientLight intensity={0.25} />
<directionalLight position={[4, 6, 3]} intensity={1.4} castShadow />
<pointLight position={[0, 2, 1]} intensity={8} distance={8} />
<spotLight position={[0, 5, 2]} angle={0.45} penumbra={0.6} />
```

واحدهای شدت با تنظیمات رندرر و نسخه Three.js تغییر می‌کنند؛ مقادیر را نسبی به صحنه بدان، مگر اینکه نورپردازی فیزیکیِ درست فعال و فهمیده شده باشد.

## خطاهای رایج

- نور محیطی آن‌قدر بالا که فرم ناپدید می‌شود
- سایه انداختن همه نورها
- نورهای نقطه‌ای بدون محدوده فاصله که همه‌چیز را تحت تأثیر می‌گذارند
- دوربین سایه خیلی کوچک/بزرگ برای صحنه
- جهت‌های سایه مخلوط بدون دلیل داستانی

## کارایی

با یک نور اصلی سایه‌ساز شروع کن. هرجا ممکن است سایه‌ها را بپز یا جعل کن. نسبت پیکسل و اندازه نقشه سایه را روی موبایل محدود کن.

## کی استفاده کنی / نکنی

جهت‌دار را برای خورشید/نور اصلی، نقطه‌ای را برای منابع محلی و موضعی را برای حوضچه‌های متمرکز نور استفاده کن. از نور محیطی به‌عنوان نور اصلی مدل‌سازی پرهیز کن.

## نکات کلیدی

- نوع نور = رفتار فضایی.
- سایه‌ها تماس و جهت را می‌فروشند.
- کارایی بخشی از طراحی نورپردازی است.
