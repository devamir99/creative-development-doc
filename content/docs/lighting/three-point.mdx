# Three-Point Lighting

## Introduction

**Three-point lighting** is a classic setup: a **key** light shapes form, a **fill** opens crushing shadows, and a **rim** (back) light separates the subject from the background.

## Why it matters

- Reads clearly in product, portrait, and UI 3D embeds.
- Teaching knobs (intensity / warm-cool) beat opaque “make it pretty” presets.
- Not physically accurate photometric units — labeled as such.

## Parameters

| Control | Role |
| --- | --- |
| Key | Primary shaping light |
| Fill | Shadow openness |
| Rim | Edge separation |
| Key temp | Cool ↔ warm color mix on the key |

## Key takeaways

- Key shapes; fill softens; rim detaches.
- Temperature shifts mood without changing placement.
- Prefer demand frameloops when scrubbing lights.
