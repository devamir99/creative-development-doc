# Creative Development Handbook

Your permanent reference for cinematic and interactive creative development.

Every lesson follows the same pattern: **See it first** in an interactive playground, then concept, why it matters, parameters, implementation, mistakes, and an exercise. Reading is optional at first — play first, understand, then go deep.

## How to use this handbook

| Mode | Do this |
|---|---|
| Learn | Follow a section top → bottom; play every demo |
| Build | Open the lesson + [Cheat Sheet](/docs/reference/cheat-sheet) for decisions |
| Review | Use [Critique Loop](/docs/direction/critique) and the 10-second checklist |
| Forget a term | [Glossary](/docs/reference/glossary) |
