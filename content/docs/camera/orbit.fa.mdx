# دوربین مداری (Orbit)

## مقدمه

یک **چرخش مداری (Orbit)** دوربین را درحالی‌که به سوژه نگاه می‌کند نگه می‌دارد و چشم روی یک کره (یا مسیر کره‌مانند) دور آن سفر می‌کند. آزیموت دور محور عمودی می‌چرخد؛ ارتفاع بالا یا پایین می‌رود؛ شعاع فاصله تا هدف است.

FOV می‌تواند ثابت بماند تا قاب‌بندی **فضایی** را جدا کنی — برخلاف زوم.

## چرا مهم است

- پیکربندسازهای محصول و میزگردان‌ها اوربیت‌اند (گاهی با ایزینگ).
- مطالعه فرم: اوربیت تغییر سیلوئت‌هایی را آشکار می‌کند که دوربین قفل پنهان می‌کند.
- در زبان فیلم، قوس / اوربیت بدون برش انرژی می‌دهد — زیاده‌روی همچنان بیننده را خسته می‌کند.

## توضیح بصری

```text
            elevation
                ↑
                ● eye (radius)
               ╱
    target ●—————— azimuth around Y
```

با تغییر آزیموت به سوژه زرد و ستون‌ها دقت کن: پارالاکس ثابت می‌کند چشم در فضا حرکت می‌کند.

## پارامترها

| پارامتر | نقش |
| --- | --- |
| آزیموت | درجه دور Y (۰ ≈ از سمت +Z) |
| ارتفاع | درجه بالای افق از مسیر هدف |
| شعاع | فاصله هدف تا چشم |
| FOV | اینجا ثابت (`40°`) تا اوربیت فضایی بماند |

## کاربردهای عملی

۱. **هیروی کفش / ساعت** — حلقه آرام آزیموت با ایزینگ ورود و خروج؛ ارتفاع ملایم.
۲. **حجم‌سازی معماری** — شعاع پهن‌تر، ارتفاع بالاتر برای حجم‌های خوانا.
۳. **دیباگ یک مش** — وقتی باید فرم را بفهمی اوربیت از دست‌کاری FOV بهتر است.

## پیاده‌سازی

```js
const phi = ((90 - elevationDeg) * Math.PI) / 180;
const theta = (azimuthDeg * Math.PI) / 180;
camera.position.set(
  target.x + radius * Math.sin(phi) * Math.sin(theta),
  target.y + radius * Math.cos(phi),
  target.z + radius * Math.sin(phi) * Math.cos(theta),
);
camera.lookAt(target);
```

`OrbitControls` در drei برای اپ‌ها خوب است؛ این آزمایشگاه برای آموزش پارامترهای کره را مستقیم در معرض می‌گذارد.

## نکات کارایی

- هنگام اسکراب `frameloop="demand"`؛ فقط هنگام اوربیت خودکار `"always"`.
- DPR را محدود کن؛ برای هر دمو یک Canvas.

## خطاهای رایج

- اوربیت هم‌زمان با زوم FOV در هر فریم — سخت می‌شود فهمید کدام متغیر چه چیزی یادت داد
- شعاع آن‌قدر کوتاه که دوربین سوژه را برش می‌دهد
- نادیده گرفتن `prefers-reduced-motion` در اوربیت خودکار

## کی استفاده کنی / نکنی

**استفاده کن** برای مطالعه فرم و حضور محصول.
**پرهیز کن** به‌عنوان تزئین بی‌پایان روی صفحه‌های پرمحتوا، یا وقتی یک زاویه ساخته‌شده واحد همین حالا داستان را می‌گوید.

## نکات کلیدی

- اوربیت = حرکت کروی چشم + نگاه ثابت.
- هنگام یادگیری اثر فضایی FOV را ثابت نگه دار.
- آزیموت / ارتفاع / شعاع سه دکمه‌ای هستند که اول از همه مهم‌اند.
