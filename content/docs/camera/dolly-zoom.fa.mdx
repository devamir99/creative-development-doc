# دالی در برابر زوم

## مقدمه

**دالی (Dolly)** دوربین را در فضا حرکت می‌دهد (اینجا: در امتداد Z به سمت سوژه).
**زوم (Zoom)** میدان دید (FOV) را عوض می‌کند درحالی‌که چشم ثابت می‌ماند.

هر دو می‌توانند کاری کنند سوژه بخش بیشتری از قاب را بگیرد. این دو **یک عملیات نیستند**. دالی **روابط فضایی** را عوض می‌کند (پارالاکس بین نزدیک و دور). زوم **مخروط نوری** را بدون جابه‌جا کردن چشم تغییر می‌دهد.

## چرا مهم است

- نماهای هیچکاکی / «سرگیجه» هر دو را عمداً ترکیب می‌کنند؛ تازه‌کارها اغلب وقتی منظورشان دالی است زوم می‌کنند (یا برعکس).
- در وب سه‌بعدی محصول و معماری: تقلید پوش‌این فقط با FOV معمولاً پارالاکس ندارد و تخت حس می‌شود.
- وضوح آموزشی: وقتی قاب‌بندی هم‌اندازه را کنار هم دیدی، دیگر این دو را یکی نمی‌گیری.

## توضیح بصری

زمین بازی سوژه زرد را در هر دو پنل تقریباً در **یک اندازه** نگه می‌دارد با این رابطه:

```text
z × tan(fov / 2) ≈ constant
```

| پنل | چه چیزی عوض می‌شود | به چه چیزی دقت کن |
| --- | --- | --- |
| **دالی** | `z` دوربین نزدیک‌تر · FOV ثابت | ستون‌ها و توده‌های دور نسبت به سوژه جابه‌جا می‌شوند (پارالاکس) |
| **زوم** | FOV باریک‌تر · `z` دوربین ثابت | سوژه به‌صورت نوری بزرگ می‌شود؛ پشته عمق بدون حرکت چشم فشرده می‌شود |

در مقدار پوش `0` هر دو طرف با خط مبنا یکی‌اند (`z=6` و `fov=40°`).

## پارامترها

| پارامتر | نقش |
| --- | --- |
| مقدار پوش | ترکیب ۰ تا ۱ از خط مبنا تا قوی‌ترین پوش هم‌اندازه |
| دالی `z` / `fov` | چشم حرکت می‌کند؛ FOV روی خط مبنا می‌ماند |
| زوم `z` / `fov` | چشم ثابت؛ FOV برای اندازه هم‌اندازه سوژه حل می‌شود |

## کاربردهای عملی

۱. **هیروی محصول** — یک دالی کوتاه (یا چرخش مداری) را برای فضای ملموس ترجیح بده؛ انیمیشن FOV را برای استایل‌سازی نوری نگه دار.
۲. **ترس / ناآرامی** — دالی‌زوم (هر دو با هم) یک افکت جداست؛ اول دو جزء آن را یاد بگیر.
۳. **سه‌بعدی توکار در رابط** — «پوش» فقط‌زومی ارزان‌تر است اما مثل کراپ خوانده می‌شود، نه حرکت.

## پیاده‌سازی

```js
// اندازه زاویه‌ای هم‌اندازه (تقریب آموزشی)
const zDolly = /* z نزدیک‌تر */;
const fovZoom =
  2 * Math.atan((zDolly / zBase) * Math.tan((fovBase * Math.PI) / 360));
// درجه: fovZoom * 180 / Math.PI
```

## نکات کارایی

- دو کانوس از سقف `dpr` پایین‌تر و `frameloop="demand"` استفاده می‌کنند.
- روی دستگاه‌های کم‌توان در هر زمان یک جلسه مقایسه را ترجیح بده.

## خطاهای رایج

- اسکیل کردن مش سوژه برای تقلید دالی
- متحرک کردن FOV و نامیدن آن حرکت دوربین
- مقایسه دالی و زوم بدون هم‌اندازه کردن سوژه (آن‌وقت تغییر اندازه را با تکنیک اشتباه می‌گیری)

## کی استفاده کنی / نکنی

**دالی** وقتی فضا و پارالاکس مهم‌اند.
**زوم** وقتی فشرده‌سازی/گسترش نوری با چشم قفل‌شده می‌خواهی.
**هر دو با هم** فقط وقتی عمداً حرکت متقابل سرگیجه‌آور را می‌خواهی.

## نکات کلیدی

- اندازه یکسان سوژه ≠ هنر یکسان دوربین.
- دالی = فضایی؛ زوم = نوری.
- قاب‌بندی هم‌اندازه تفاوت واقعی را در پس‌زمینه آشکار می‌کند.
