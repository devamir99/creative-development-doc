# Visual Language

## See it first

Three cards enter. **Consistent** = one accent + one ease. **Inconsistent** = random color + random easing. Feel the difference before reading.

<VisualLanguagePlayground />

## Introduction

A **visual language** is the smallest set of recurring decisions that make an experience feel like itself.

## Why it matters

- Without a language, every page reinvents taste.
- With one, new screens compose faster.

## Checklist

1. One accent signal
2. Type roles (display / body / mono)
3. Motion verbs (shared easing family)
4. Camera verbs
5. Motifs that return

## Key takeaways

- Language = constraints that create recognition.
- Document verbs, not only tokens.
