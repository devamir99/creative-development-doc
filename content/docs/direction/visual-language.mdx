# Visual Language

## Introduction

A **visual language** is the smallest set of recurring decisions that make an experience feel like itself: type, color, motion curves, camera grammar, and motif.

## Why it matters

- Without a language, every page reinvents taste.
- With one, new screens compose faster and critiques get sharper.

## Practical checklist

1. **Accent** — one primary signal color (this lab: yellow `rgb(250,250,5)`).
2. **Type roles** — display vs body vs mono for code.
3. **Motion verbs** — e.g. anticipate-then-go; avoid random easings.
4. **Camera verbs** — orbit for product, locked FOV for study, etc.
5. **Motifs** — shapes or transitions that return.

## Key takeaways

- Language = constraints that create recognition.
- Document verbs, not only tokens.
