# کارگردانی تایپوگرافی و زبان حرکت

## اول ببین

<KineticTypePlayground />

تایپ لحن دارد. اندازه، وزن، فاصله‌گذاری و حرکتش تصمیم می‌گیرند که نجوا کند، دستور بدهد، جشن بگیرد یا هشدار دهد.

## کارگردانی تایپوگرافی

| تصمیم | اثر |
|---|---|
| شخصیت تایپ‌فیس | رسمی، فنی، گرم، سرکش |
| کنتراست مقیاس | درام و سلسله‌مراتب |
| وزن | اقتدار و تراکم |
| ترکینگ/لدینگ | هوا، فوریت، لوکس‌بودن، خوانایی |
| حروف بزرگ/کوچک | فریاد، برچسب، جمله، نشان برند |
| تراز | نظم، عدم تقارن، تنش تحریریه‌ای |
| مونو در برابر سنس/سریف | نقش‌های سیستمی/فنی در برابر انسانی/تحریریه‌ای |

## زبان حرکت

زبان حرکت فعل‌ها را تعریف می‌کند، نه افکت‌های تصادفی را:

| فعل | امضای حرکت |
|---|---|
| Arrive | ease-out، خیزش ملایم |
| Inspect | چرخش مداری/دالی آرام، مکث‌های پایدار |
| Snap | مدت کوتاه، نشستن با بک/فنر |
| Flow | ease-in-out، پلکانی هم‌پوشان |
| Alarm | برش سریع، کنتراست بالا، تزئین حداقلی |

هر محصول باید مجموعه کوچکی از مدت‌ها، ایزینگ‌ها، فاصله‌ها و انواع گذار داشته باشد که تکرار می‌شوند.

## چرا مهم است

تایپوگرافی اغلب بزرگ‌ترین عنصر بصری در وب است. اگر کارگردانی تایپ عمومی باشد، تجربه هم عمومی می‌شود، حتی با WebGL.

## پارامترها

| پارامتر | اثر کارگردانی |
|---|---|
| نسبت نمایشی/بدنه | درام |
| طول خط | راحتی خواندن |
| کنتراست وزن | سلسله‌مراتب لحن |
| واحد انیمیشن حروف | کلمه (معنا) در برابر حرف (بافت) |
| فاصله حرکت | اعتمادبه‌نفس در برابر عصبی‌بودن |
| خانواده ایزینگ | متریال/فیزیک برند |

## کاربردهای عملی

۱. **لوکس:** هوای زیاد، وزن‌های مهارشده، ease-out آرام.
۲. **آزمایشگاه فنی:** برچسب‌های مونو، تایپ شبکه‌ای، حرکت دقیق و تند.
۳. **محصول بازیگوش:** مقیاس متغیر، اکسنت‌های فنری، جهش‌های گروه‌کلمه‌ای.
۴. **تحریریه‌ای:** نمایشی سریف، ستون‌های قوی، گذارهای آرام صفحه.

## پیاده‌سازی

نقش‌های تایپ و توکن‌های حرکت را تعریف کن:

```css
--font-display: ...;
--ease-arrive: cubic-bezier(.22, 1, .36, 1);
--duration-arrive: 520ms;
```

هنگام تقسیم متن برای انیمیشن، متن DOM دسترس‌پذیر را دست‌نخورده نگه دار.

## خطاهای رایج

- انتخاب فونت بر اساس ترند، بدون لحن
- متحرک‌کردن حروف در پاراگراف‌های طولانی
- تایپ نمایشی بیش از حد بزرگ برای محتوای موبایل
- هر تیتر با یک افکت متفاوت

## دسترس‌پذیری

کنتراست، ارتفاع خط، متن مقیاس‌پذیر و جایگزین‌های reduced-motion را حفظ کن. از متنی که فقط به‌صورت کانوس/تصویر رندر می‌شود پرهیز کن.

## کی استفاده کنی / نکنی

برای هر تجربه بزرگ، تایپ را کارگردانی کن. برای محتوای حقوقی، خطا و آموزشی متراکم از تایپ جنبشی پرهیز کن.

## نکات کلیدی

- تایپ انتخاب بازیگر و لحن است.
- زبان حرکت یک دستور زبان قابل‌استفاده دوباره است.
- کلمه‌ها معمولاً باید به‌صورت واحدهای معنا متحرک شوند.
