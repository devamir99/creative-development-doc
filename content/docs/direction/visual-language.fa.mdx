# زبان بصری

## اول ببین

سه کارت وارد می‌شوند. **Consistent** = یک اکسنت + یک ایزینگ. **Inconsistent** = رنگ تصادفی + ایزینگ تصادفی. پیش از خواندن، تفاوت را حس کن.

<VisualLanguagePlayground />

## مقدمه

**زبان بصری (Visual Language)** کوچک‌ترین مجموعه تصمیم‌های تکرارشونده‌ای است که باعث می‌شود یک تجربه حس خودش را داشته باشد.

## چرا مهم است

- بدون یک زبان، هر صفحه سلیقه را از نو اختراع می‌کند.
- با یک زبان، صفحه‌های تازه سریع‌تر ترکیب‌بندی می‌شوند.

## چک‌لیست

1. یک سیگنال اکسنت
2. نقش‌های تایپ (نمایشی / بدنه / مونو)
3. فعل‌های حرکت (خانواده ایزینگ مشترک)
4. فعل‌های دوربین
5. موتیف‌هایی که بازمی‌گردند

## نکات کلیدی

- زبان = محدودیت‌هایی که شناخت می‌سازند.
- فعل‌ها را مستند کن، نه فقط توکن‌ها را.
