# کتابچه توسعه خلاقانه

مرجع همیشگی تو برای توسعه خلاقانه سینمایی و تعاملی.

هر درس یک الگو دارد: اول در دموی تعاملی **ببین و بازی کن**، بعد مفهوم، چرایی، پارامترها، پیاده‌سازی، خطاها و تمرین. اول بازی کن؛ بعد عمیق شو.

## چطور از این کتاب استفاده کنی

| حالت | چه کار کن |
|---|---|
| یادگیری | هر بخش را از بالا به پایین برو؛ با همه دموها بازی کن |
| ساختن | درس + [برگه تقلب](./reference/cheat-sheet) را برای تصمیم‌ها باز کن |
| بازبینی | از [چرخه نقد](./direction/critique) و چک‌لیست ۱۰ ثانیه‌ای استفاده کن |
| فراموشی اصطلاح | [واژه‌نامه](./reference/glossary) |
