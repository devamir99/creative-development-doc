# کتابچه توسعه خلاقانه

مرجع دائمی شما برای توسعه خلاقانهٔ سینمایی و تعاملی.

هر درس یک الگو دارد: اول در دموی تعاملی **ببینید و بازی کنید**، بعد مفهوم، چرایی، پارامترها، پیاده‌سازی، خطاهای رایج و تمرین. اول بازی کنید؛ بعد عمیق شوید.

## چطور از این کتاب استفاده کنید

| حالت | چه کار کنید |
|---|---|
| یادگیری | هر بخش را از بالا به پایین بروید و با همهٔ دموها بازی کنید |
| ساختن | درس را کنار [برگه تقلب](./reference/cheat-sheet.mdx) برای تصمیم‌گیری باز نگه دارید |
| بازبینی | از [چرخه نقد](./direction/critique.mdx) و چک‌لیست ۱۰ ثانیه‌ای استفاده کنید |
| فراموشی اصطلاح | [واژه‌نامه](./reference/glossary.mdx) |
